# 👤 GitHub User Finder

**Автор:** Клюшина Ангелина Романовна
**Версия:** 1.0

## Описание программы

«GitHub User Finder» — это графическое приложение для поиска пользователей на платформе GitHub с помощью официального **GitHub API**.
*   **Поиск:** Находит пользователей по логину или имени.
*   **Избранное:** Позволяет сохранять интересных пользователей.
*   **Просмотр профиля:** Открывает страницу пользователя на GitHub.com.
*   **Автономность:** История избранного сохраняется локально.

## Системные требования и установка

1.  **Python 3.8+**
2.  **Библиотеки:**
    *   `tkinter` (стандартная библиотека).
    *   `requests` (для работы с сетью).
3.  **Установка зависимостей:**
    ```bash
    pip install requests
    ```
4.  **Запуск:**
    ```bash
    python main.py
    ```
5.  **GitHub API:**
    *   Приложение использует **публичный API**, который не требует личного токена (API Key).
    *   Лимит для анонимных запросов: ~60 запросов в час.

## Как использовать API (GitHub Search API)

Приложение использует эндпоинт `GET /search/users`.
*   **Параметр запроса:** `q` (например, `q=defunkt`).
*   **Ответ:** Содержит массив `items` с данными о пользователях (`login`, `avatar_url`, `html_url`).
*   Документация: [docs.github.com](https://docs.github.com/en/rest/search/search?apiVersion=2022-11-28#search-users).

## Примеры использования (Тесты)

| **Действие** | **Ввод / Действие** | **Ожидаемый результат** |
| :--- | :--- | :--- |
| **Тест 1: Поиск** | Ввести `torvalds` и нажать «Поиск» | В таблице отобразится пользователь `torvalds`. |
| **Тест 2: Ошибка ввода** | Оставить поле пустым и нажать «Поиск» | Появится окно с ошибкой: «Поле поиска не должно быть пустым». |
| **Тест 3: Добавить в избранное** | Найти `mojombo` -> Клик правой кнопкой по строке | Пользователь добавлен в избранное. Строка подсветится желтым. |
| **Тест 4: Открыть профиль** | Найти любого пользователя -> Двойной клик по строке | Профиль пользователя откроется в браузере по умолчанию. |
| **Тест 5: Удалить из избранного** | Найти пользователя в избранном -> Клик правой кнопкой | Пользователь удален из избранного. Подсветка исчезнет. |
